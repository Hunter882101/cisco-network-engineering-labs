# Enterprise Network Services Lab

## Project Overview

Designed and configured a simulated enterprise network using Cisco routers, switches, PCs, and servers.

The lab demonstrates the implementation of essential network services, including DHCP, DNS, NAT/PAT, and an HTTP web server.

## Network Topology

![Network Topology](topology.png)

## Technologies Used

* Cisco Packet Tracer
* Cisco Routers
* Cisco Switches
* DHCP
* DNS
* NAT/PAT
* IPv4 Addressing
* HTTP Web Server
* Cisco IOS
* Ping and Network Verification Tools

## Network Objectives

1. Configure DHCP for automated IP address assignments.
2. Configure DNS to resolve domain names to IP addresses.
3. Implement NAT/PAT for private LAN devices.
4. Configure an HTTP web server.
5. Enable client access to a hosted website.
6. Troubleshoot network services and connectivity.

## Configuration

### DHCP

Configured DHCP to automate IP address assignments for client devices.

### DNS

Configured DNS services to resolve domain names to IP addresses.

### NAT/PAT

Implemented Network Address Translation and Port Address Translation to enable private LAN devices to communicate with an external simulated network.

### HTTP Web Server

Deployed and configured an HTTP web server, enabling clients to access a hosted website through a web browser.

## Troubleshooting

Troubleshot network connectivity, routing, and NAT configurations using Cisco IOS commands, ping, and network verification tools.

Troubleshooting areas included:

* IP addressing
* DHCP operation
* DNS resolution
* Routing
* NAT/PAT configuration
* Web server connectivity

## Verification Commands and Tools

```text
show ip interface brief
show ip route
ping
```

Additional verification was performed using network tools and web browser access to the hosted website.

## Verification Results

* Verified automated client IP address assignments.
* Tested DNS name resolution.
* Tested communication through NAT/PAT.
* Accessed the hosted HTTP website from client devices.
* Troubleshot connectivity and routing issues.
